# v0.33 Notes

Implemented the tensor-hook/activation-masking design for GradDotProd. Key changes:
- Replaced module backward hooks with output tensor hooks for dot-product computation in `ghostEngines/autograd_grad_sample_dotprod.py`.
- Added activation masking in `_NamedSavedTensorManager.unpack_hook`, including loss-reduction scaling for train/val, plus saved-tensor metadata tracking.
- Added special handling:
  - Embeddings mask `grad_output` in the tensor hook (indices are non-float, so activation masking is skipped).
  - RMSNorm/LayerNorm use a full backward hook to recompute `grad_input` from the original activation, and LayerNorm also recomputes train-only parameter grads.
- Updated `GradDotProdEngine.prepare_gradients()` to accept autograd `.grad` when `train_grad` is absent.

Tests not run.
